## 当前读到的关键点

- 自报置信度与回答准确率是不同对象；校准误差下降，也不保证区分正确和错误的能力提高。
- 冻结教师为候选答案提供相对判别信号，学生在触发条件满足时进行适应；这并不是获得了独立的正确性标签。
- 正文和附录的 NormPTrue 写法存在差异，不能把其中任意一种直接当作已核实的代码实现。
