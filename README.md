## 怎么读这些笔记

- **先看流程，再看细节。** 每篇论文有独立入口，按研究问题和工作流程展开。
- **讲解跟着实例走。** HealthBench 使用公开题库的真实题干与 rubric；为了说明算法而构造的分数，会明确标为教学示例。
- **点击回到原文。** 关键结论附有论文页码、官方代码或数据链接；英文原文可在相应笔记中展开。
- **区分读懂、核查与复现。** 论文报告的结果、笔记中的解释和仍待核实的问题分别标明。目前收录的是阅读笔记，没有独立复现实验结果。
